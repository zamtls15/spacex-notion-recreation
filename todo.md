# Public GitHub Publishing Checklist

- [ ] Review repository contents for secrets, generated build artifacts, and unnecessary files.
- [ ] Add a concise project README with setup, development, build, and feature notes.
- [ ] Initialize or update the local git repository and create a clean commit.
- [ ] Create a new public GitHub repository and push the project.
- [ ] Verify the public repository URL and default branch contents.
- [ ] Report the repository link to the user.
